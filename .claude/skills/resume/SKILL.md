Run `npm run goals -- status`, inspect `git status --short --branch`, recent commits, and the active objective evidence. Resume the first incomplete task, not the beginning of the plan. If state and Git disagree, preserve work, diagnose, and update state through the goal CLI. Never reset or discard unknown changes.
