# Autonomous decisions

Proceed without `AskUserQuestion` for aesthetic choices, file naming, component boundaries, ordinary library usage, test structure, and reversible implementation decisions. Prefer the option that maximizes visual impact while meeting performance and accessibility gates. Only stop for missing external authorization/credentials, destructive irreversible choices, or contradictory hard requirements. Record a blocker in goal state before asking.

Never hide incomplete work behind optimistic language. Use state transitions and command evidence.
